# PB-31 — Selected City Population

## Requirement

Report the population of a selected city.

Supported commands:

```text
PB-31 <city>
--population-city <city>
```

City names containing spaces are supported. The query uses a parameterised city-name
filter and returns a clear no-data message when the selected city is absent.

## Automated verification

The tests cover:

- a selected city population;
- city names containing spaces;
- unknown, missing, and blank city input;
- both supported command forms; and
- database errors without exposing connection details.

Run the suite with:

```bash
mvn clean verify
```

## Official World Database check

After starting the coursework database, compare the command output with this
direct equivalent query:

```sql
SELECT Name, Population
FROM city
WHERE Name = 'London';
```

Example application invocation:

```bash
java -jar target/population-reporting-system.jar PB-31 London
```
