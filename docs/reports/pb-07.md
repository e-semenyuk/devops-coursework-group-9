# PB-07: Cities in the World by Population

**Issue:** [#14 — Cities in the world by population](https://github.com/e-semenyuk/devops-coursework-group-9/issues/14)

**Use case:** [PB-07: Produce World City Population Report](../USE_CASES/PB-07.md)

## 1. Commands

Run the report using either supported command:

```bash
docker compose run --build --rm app PB-07
docker compose run --rm app --cities-world-population
```

Both commands invoke the world city population report.

## 2. Report Behaviour

The report retrieves city data from the `city` table and joins it to the `country` table using `country.Code = city.CountryCode`.

The report contains these columns:

- Name
- Country
- District
- Population

Cities are ordered by population in descending order. City name, country code and city ID provide additional ordering when populations are equal.

Population values are formatted with thousands separators. If the query returns no cities, the application displays `No cities found.` Database errors produce a non-zero exit code and a general error message without exposing connection details.

## 3. Automated Tests

`CitiesWorldPopulationTest` covers:

- Successful report generation and output format.
- Descending population order and ordering of cities with equal populations.
- Equivalent output from `PB-07` and `--cities-world-population`.
- Handling of an empty city result.
- Database failure handling and protection against exposing sensitive connection details.

The tests use the project's test database.
