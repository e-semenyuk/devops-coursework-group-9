# PB-26 — World Population

## Requirement

Report the total population of the world.

Supported commands:

```text
PB-26
--population-world
```
The query calculates the total world population by summing the Population
column from the country table.

## Automated verification
The tests cover:
- the total world population;
- both supported command forms;
- unexpected arguments; and
- database errors without exposing connection details.
Run the suite with:

```bash
mvn clean verify
```
## Official World Database check

After starting the coursework database, compare the command output with this
direct equivalent query:

```sql
SELECT SUM(Population) AS world_population
FROM country;
```
Example application invocation:

```bash
java -jar target/population-reporting-system.jar PB-26
```
