## 2. Purpose

PB-10 generates a population report for all cities belonging to a specified country using the official coursework world database.

The report enables stakeholders to compare city populations within a country, ordered from largest to smallest.

The report displays four required columns:

- Name
- Country
- District
- Population

## 4. Implementation

The implementation adds `findByCountry(String country)` to `CityPopulationRepository.java`.

The repository queries the `city` and `country` tables using an inner join on the country code.

```sql
SELECT city.Name AS CityName,
       country.Name AS CountryName,
       city.District,
       city.Population
FROM city
INNER JOIN country
    ON country.Code = city.CountryCode
WHERE country.Name = ?
ORDER BY city.Population DESC,
         city.Name ASC,
         country.Code ASC,
         city.ID ASC;
```

The country filter uses a parameterised prepared statement.

The query returns all matching cities without applying a top-N limit.

Population is sorted in descending order, with additional columns providing deterministic ordering where population values are equal.

The existing `CityReportFormatter` produces readable output, including comma-separated population values.
