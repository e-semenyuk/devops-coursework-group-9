# PB-04: Top N countries in the world by population

[Use case](../USE_CASES/PB-04.md).

```bash
docker compose run --build --rm app PB-04 10
docker compose run --rm app --top-countries-world 10
```

Both command forms produce the same report. N must be a positive integer. The
report includes Code, Name, Continent, Region, Population and Capital, ordered
by population descending; ties are ordered by country name and code. If fewer
than N countries are available, all available countries are displayed. Empty
country data displays `No countries found.` Invalid arguments exit 2, and
database errors exit 1 without exposing connection details.

The automated tests use an isolated H2 database in MySQL compatibility mode.
`TopCountryReportTest` covers population ordering and stable ties, limiting the
results, requesting more countries than are available, command aliases,
invalid N values and arguments, and safe database errors. Run the focused tests
with:

```bash
docker run --rm -u "$(id -u):$(id -g)" \
  -v "$PWD":/workspace -w /workspace \
  maven:3.9-eclipse-temurin-17 \
  mvn -Dtest=TopCountryReportTest test
```
