# PB-03: Countries in a region by population

[Use case](../USE_CASES/PB-03.md).

```bash
docker compose run --build --rm app PB-03 "North America"
docker compose run --rm app --countries-region "North America"
```

Both command forms produce the same report. The region name is matched exactly
after trimming surrounding whitespace. The report includes Code, Name,
Continent, Region, Population and Capital, ordered by population descending;
ties are ordered by country name and code. Countries are retained if their
capital is missing or its city record does not match the country. Missing
capitals display as `N/A`. A blank region is invalid; a region with no matching
countries displays `No countries found.` Invalid arguments exit 2, and database
errors exit 1 without exposing connection details.

The automated tests use an isolated H2 database in MySQL compatibility mode.
`CountryRegionReportTest` covers region filtering, descending population order
and stable ties, equivalent command aliases, unknown and SQL-like region values,
invalid arguments, and safe database errors. Run the focused tests with:

```bash
docker run --rm -u "$(id -u):$(id -g)" \
  -v "$PWD":/workspace -w /workspace \
  maven:3.9-eclipse-temurin-17 \
  mvn -Dtest=CountryRegionReportTest test
```
