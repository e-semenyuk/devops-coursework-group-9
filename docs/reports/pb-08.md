# PB-08: Cities in a Continent by Population

**Issue:** [#15 — Cities in a continent by population](https://github.com/e-semenyuk/devops-coursework-group-9/issues/15)

**Dependency:** PB-07 (#14)

## 1. Report Purpose

PB-08 generates a population report for all cities in a specified continent, ordered from largest to smallest population.

The report displays:

- Name
- Country
- District
- Population

Unlike PB-13, which returns the top N cities in a continent, PB-08 does not impose a result limit.

## 2. Commands

The report supports both commands:

```bash
docker compose run --rm app PB-08 Asia
docker compose run --rm app --cities-continent-population Asia
```

The continent argument can be replaced with another valid continent name from the coursework world database.

## 3. Query Implementation

The report joins the `city` and `country` tables using the country code and filters by continent using a parameterised query.

```sql
SELECT city.Name AS CityName,
       country.Name AS CountryName,
       city.District,
       city.Population
FROM city
INNER JOIN country ON country.Code = city.CountryCode
WHERE country.Continent = ?
ORDER BY city.Population DESC,
         city.Name ASC,
         country.Code ASC,
         city.ID ASC;
```

The continent value is supplied through a prepared statement rather than inserted directly into the SQL string.

## 4. Report Behaviour

- Retrieves cities belonging to the specified continent.
- Orders cities by descending population, with deterministic ordering for ties.
- Formats population values with thousands separators.
- Displays `No cities found.` when no matching records exist.
- Rejects missing or blank continent arguments.
- Returns a general error message for database failures without exposing connection details.
