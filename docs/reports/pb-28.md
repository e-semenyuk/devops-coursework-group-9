# PB-28 — Selected Region Population

## Requirements 

Report the total population of a selected region.

Supported commands:

```text
PB-28 <region>
--population-region <region>
```

The query calculates the total population for the selected region by summing the Population
column from the country table using a parameterised region filter.

## Automated verification
The tests cover:

- the selected region population;

- unknown, missing, and blank region input;

- both supported command forms;

- readable output formatting; and

- database errors without exposing connection details.

Run the suite with:


```bash
mvn clean verify
```

## Official World Database check
After starting the coursework database, compare the command output with this
direct equivalent query:

```sql
SELECT Region, SUM(Population) AS region_population
FROM country
WHERE Region = 'Western Europe'
GROUP BY Region;
```

Example application invocation:
```bash
java -jar target/population-reporting-system.jar PB-28 "Western Europe"
```
