# PB-30 - Selected District Population

## Requirement

Report the total population of a selected district.

Supported commands:

```text
PB-30 <district>
--population-district <district>
```

District names containing spaces are supported.

## Automated Verification

The implementation includes tests for:

- Selected district population
- District names containing spaces
- Unknown districts
- Missing or blank district input
- Supported command formats
- Database error handling

`mvn clean verify` passed successfully during the Docker build.

The Docker image was also built successfully using:

```text
docker build -t group9-pb30-test .
```
