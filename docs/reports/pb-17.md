# PB-17: Capital cities in the world by population

Issue: #24

```bash
java -jar target/population-reporting-system.jar --capitals-world
docker compose run --build --rm app --capitals-world
```

Import the agreed coursework `world` database first, following `database/README.md`.
The report joins `country.Capital` to `city.ID`, checks the city's country code,
and prints Name, Country, Population. It sorts by **city** population descending,
then city name and country code for deterministic ties. Countries without a
matching capital are omitted. Empty results print `No capital cities found.`

Exit status: 0 for a successful report (including empty results), 2 for invalid
arguments, and 1 for database errors. Database errors do not expose driver details.

## Verification

Run `mvn clean verify`. Tests execute the SQL against an isolated H2 database in
MySQL compatibility mode, including non-capital cities, missing capitals, invalid
country links, tied populations, output formatting, empty results and safe errors.
These fixture tests complement validation against the coursework MySQL dataset.
