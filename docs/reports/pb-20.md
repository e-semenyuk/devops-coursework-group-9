# PB-20: Top N capital cities in the world

Issue: #27. Reuses the shared capital-report code from PB-17.

```bash
java -jar target/population-reporting-system.jar --top-capitals-world 5
docker compose run --build --rm app --top-capitals-world 5
```

N must be an integer from 1 to 2147483647. Zero, negative, non-numeric, fractional,
blank, overflowing or missing values are rejected before opening a connection.
The query sorts by city population and deterministic tie-breakers **before**
applying a parameterised `LIMIT`. Fewer than N matches returns all available rows.
Columns, empty-result messages and exit statuses follow [PB-17](pb-17.md).

Tests cover ranking before limiting, ties at the limit, oversized N, empty data,
all invalid N classes, argument counts and formatted command output.
Run `mvn clean verify`.
