# PB-13: Top N cities in a continent

Issue: #20. [Use case](../USE_CASES/PB-13.md).

```bash
java -jar target/population-reporting-system.jar PB-13 "Europe" 5
docker compose run --build --rm app --top-cities-continent "Europe" 5
```

Both command forms select the same report. Names and N are bound JDBC parameters.
N must be a positive integer up to 2147483647. Blank locations, missing/extra
arguments and invalid N exit 2 before connecting. Unknown locations or no matches
display `No cities found.` without a report table. Database errors exit 1 without
exposing connection details.

The query joins cities to countries, filters by continent, orders by city population
descending (then city name, country code and city ID for stable ties), and applies
LIMIT last. All available rows are returned when fewer than N match. Output
includes Name, Country, District and Population.

Synthetic Scottish/UK fixtures test filter-before-limit behaviour, non-capital
cities, ties, unknown and SQL-like inputs, oversized N, empty data, argument
validation, both command forms and safe database errors. Run `mvn clean verify`.
