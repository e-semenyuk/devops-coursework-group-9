# PB-18: Capital cities in a continent by population

Issue: #25. Builds on PB-17 (#24).

```bash
java -jar target/population-reporting-system.jar --capitals-continent "Europe"
docker compose run --build --rm app --capitals-continent "North America"
```

Supply exactly one non-blank continent; quote names containing spaces. Leading
and trailing whitespace is removed. The continent is bound as a JDBC parameter
against `country.Continent`; sorting, columns, empty results, and error exit codes
follow [PB-17](pb-17.md). An unknown continent prints `No capital cities found.`

Tests cover filtering, population order, quoted names, SQL-like input, missing and
blank arguments, and extra arguments. Run `mvn clean verify`.

## MySQL execution evidence

Using the same MySQL 8.4.11 dataset recorded in PB-17, `--capitals-continent Europe`
returned 46 rows. First five rows:

```text
Name | Country | Population
Moscow | Russian Federation | 8,389,200
London | United Kingdom | 7,285,000
Berlin | Germany | 3,386,667
Madrid | Spain | 2,879,052
Roma | Italy | 2,643,581
```

`mvn clean verify`: 13 tests passed. Fixture populations are synthetic test values,
while the output above comes from the team's historical world dataset.
