# PB-06: Top N countries in a region by population

[Use case](../USE_CASES/PB-06.md).

```bash
docker compose run --build --rm app PB-06 "Southern and Central Asia" 5
docker compose run --rm app --top-countries-region "Southern and Central Asia" 5
```

Both command forms are supported; arguments are region, then N. The region is
matched exactly after trimming surrounding whitespace, and N must be a positive
integer. Countries in the selected region are ordered by population descending;
ties are ordered by country name and code. Only matching countries count toward
the limit. If fewer than N countries are available, all matching countries are
shown. A region with no matching countries displays `No countries found.` Invalid
arguments exit 2, and database errors exit 1 without exposing connection details.

The automated tests use an isolated H2 database in MySQL compatibility mode.
`TopCountryRegionReportTest` covers region filtering before limiting, descending
population order and stable ties, both command forms, fewer than N results,
unknown and SQL-like regions, invalid arguments, and safe database errors. Run
the focused tests with:

```bash
docker run --rm -u "$(id -u):$(id -g)" \
  -v "$PWD":/workspace -w /workspace \
  maven:3.9-eclipse-temurin-17 \
  mvn -Dtest=TopCountryRegionReportTest test
```
