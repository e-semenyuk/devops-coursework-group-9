# PB-32 - Five-Language Population Report

## Requirement

Produce a global report showing the number of people who speak Chinese,
English, Hindi, Spanish, and Arabic, together with the percentage of the
world population who speak each language.

Results are ordered from greatest to smallest number of speakers.

Supported commands:

```text
PB-32
--language-population
```

The estimated number of speakers is calculated using each country's
population and the language percentage stored in the `countrylanguage`
table.

The percentage of world population is calculated using the total
population from the `country` table.

## Automated verification

The tests cover:

- the five required languages;

## Official World Database check

After starting the coursework database, compare the application output
with this direct equivalent query:

```sql
SELECT cl.Language,
       ROUND(SUM(c.Population * cl.Percentage / 100)) AS Speakers,
       ROUND(
           (SUM(c.Population * cl.Percentage / 100)
           / (SELECT SUM(Population) FROM country)) * 100,
           2
       ) AS WorldPercentage
FROM countrylanguage cl
JOIN country c ON c.Code = cl.CountryCode
WHERE cl.Language IN ('Chinese', 'English', 'Hindi', 'Spanish', 'Arabic')
GROUP BY cl.Language
ORDER BY Speakers DESC;
```
