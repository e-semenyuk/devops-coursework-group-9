# PB-19: Capital cities in a region by population

Issue: #26. Reuses the shared capital-report code from PB-17/PB-18.

```bash
java -jar target/population-reporting-system.jar --capitals-region "British Islands"
docker compose run --build --rm app --capitals-region "British Islands"
```

The region must be one non-blank argument. Quote names containing spaces. The
value is bound as a JDBC parameter against `country.Region`, never concatenated
into SQL. Unknown regions produce `No capital cities found.` Columns, sorting,
and exit statuses follow [PB-17](pb-17.md).

Tests distinguish region filtering from continent filtering and cover whitespace,
apostrophes, SQL-like input, invalid argument counts, empty results and formatting.
Run `mvn clean verify`.

## MySQL execution evidence

MySQL 8.4.11, using the dataset recorded in PB-17. Complete output for
`--capitals-region "British Islands"`:

```text
Name | Country | Population
London | United Kingdom | 7,285,000
Dublin | Ireland | 481,854
```
