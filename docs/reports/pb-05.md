
# PB-05: Top N countries in a continent by population

[Use case](../USE_CASES/PB-05.md).

## Commands

```bash
docker compose run --build --rm app PB-05 Asia 5
docker compose run --rm app --top-countries-continent Asia 5
```

Both command forms produce the same report.

The report displays Code, Name, Continent, Region, Population and Capital. Countries are filtered by continent and ordered by population descending, with country name and code as tie-breakers.

N must be a positive integer. If fewer than N countries exist, all matching countries are returned. Empty results display `No countries found.` Invalid arguments exit with code 2, while database errors exit with code 1 without exposing connection details.

Automated tests in `TopCountriesContinentTest` cover filtering, ordering, limits, command aliases, invalid inputs, empty results and safe database errors.
