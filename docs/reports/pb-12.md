# PB-12: Top N cities in the world

Issue: #19. [Use case](../USE_CASES/PB-12.md).

```bash
java -jar target/population-reporting-system.jar --top-cities-world 5
java -jar target/population-reporting-system.jar PB-12 5
docker compose run --build --rm app --top-cities-world 5
```

Both command forms select the same report. `N` must be a positive integer from
1 to 2147483647. Zero, negative, non-numeric, fractional, blank, overflowing or
missing values are rejected before opening a database connection. Extra arguments
and repository limits that are not positive are also rejected.

The repository joins cities to countries, orders by population descending and uses
city name, country code and city ID as deterministic tie-breakers before a
parameterised `LIMIT`. Fewer than `N` available rows returns every match. Output
contains Name, Country, District and Population; an empty result is reported as
`No cities found.`. Database failures return exit status 1 without exposing
connection details.

Tests cover ranking and limiting, ties through the shared deterministic fixture,
oversized `N`, empty city data, invalid `N` values, missing and extra arguments,
both command forms, and safe database errors. Run `mvn clean verify`.
