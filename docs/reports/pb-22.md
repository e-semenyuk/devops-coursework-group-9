# PB-22: Top N capital cities in a region

Issue: #29. Builds on the region filter (PB-19) and Top N query (PB-20).

```bash
java -jar target/population-reporting-system.jar --top-capitals-region "British Islands" 1
docker compose run --build --rm app --top-capitals-region "British Islands" 5
```

Arguments are **region, then N**. Quote region names containing spaces. The region
must not be blank and N must be an integer from 1 to 2147483647. Both values are
bound JDBC parameters. Only matching capital cities are ranked and limited;
asking for more rows than exist returns all available matches. Columns,
empty-result messages and exit statuses follow [PB-17](pb-17.md).

Tests distinguish region from continent filtering, put a larger capital outside
the region, and cover excessive N, unknown/SQL-like regions, invalid N,
whitespace, missing/extra arguments and formatted output. Run `mvn clean verify`.

## MySQL execution evidence

MySQL 8.4.11 with the dataset recorded in PB-17;
`--top-capitals-region "British Islands" 1`:

```text
Name | Country | Population
London | United Kingdom | 7,285,000
```

Requesting N = 5 correctly returns the two available matches:

```text
Name | Country | Population
London | United Kingdom | 7,285,000
Dublin | Ireland | 481,854
```

`mvn clean verify`: all 47 tests passed across PB-17 through PB-22 and database
configuration. Each issue has its own branch, commit, tests and report evidence.
