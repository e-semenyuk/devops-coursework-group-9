# PB-27 — Selected Continent Population

## Requirement

Report the total population of a selected continent.

Supported commands:

```text
PB-27 <continent>
--population-continent <continent>
```
The query calculates the total population for the selected continent by summing the Population
column from the country table using a parameterised continent filter.

## Automated verification
The tests cover:
- the selected continent population;
- unknown, missing, and blank continent input;
- both supported command forms;
- readable output formatting; and
- database errors without exposing connection details.
  Run the suite with:

```bash
mvn clean verify
```

## Official World Database check

After starting the coursework database, compare the command output with this
direct equivalent query:
```sql
SELECT Continent, SUM(Population) AS continent_population
FROM country
WHERE Continent = 'Europe'
GROUP BY Continent;
```
Example application invocation:

```bash
java -jar target/population-reporting-system.jar PB-27 Europe
```
