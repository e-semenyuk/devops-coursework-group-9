# PB-23: Population distribution by continent

Issue: #30. [Use case](../USE_CASES/PB-23.md).

```bash
java -jar target/population-reporting-system.jar PB-23
docker compose run --build --rm app --population-by-continent
```

Both command forms report every continent, ordered by name, with total population,
population in recorded cities, and population outside recorded cities. Each of the
last two categories includes its percentage of the group total.

City populations are summed per country before a LEFT JOIN to countries. Each
country total is counted once, including countries with no recorded cities.
Totals use Java long values. Non-city population is total minus city population;
percentages use decimal arithmetic rounded to two places, or N/A when total is zero.
The world dataset lists selected cities, so the complement means population outside
those recorded cities, not a separately measured rural population.

Inconsistent source data (city total greater than country total) is preserved and
flagged with a warning. No values are silently clamped. Empty data prints
`No population data found.`; database failures print a safe message and exit 1.
Unexpected arguments exit 2 before connecting.

Tests cover countries with multiple/no cities, orphan cities, large totals,
zero denominators, rounding, locale independence, inconsistent source data,
empty data, both command forms and error handling. Run `mvn clean verify`.
