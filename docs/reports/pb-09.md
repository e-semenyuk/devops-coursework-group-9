# PB-09: Cities in a Region by Population

**Issue:** [#16 — Cities in a region by population](https://github.com/e-semenyuk/devops-coursework-group-9/issues/16)

**Dependency:** PB-07 (#14)

## 1. Report Purpose

PB-09 generates a population report for all cities in a specified region, ordered from largest to smallest population.

The report displays:

- Name
- Country
- District
- Population

Unlike PB-14, which returns the top N cities in a region, PB-09 does not impose a result limit.

## 2. Commands

The report supports both commands:

```bash
docker compose run --rm app PB-09 "British Islands"
docker compose run --rm app --cities-region-population "British Islands"
```

The region argument can be replaced with another valid region name from the coursework world database.

## 3. Query Implementation

The report joins the `city` and `country` tables using the country code and filters by region using a parameterised query.

```sql
SELECT city.Name AS CityName,
       country.Name AS CountryName,
       city.District,
       city.Population
FROM city
INNER JOIN country ON country.Code = city.CountryCode
WHERE country.Region = ?
ORDER BY city.Population DESC,
         city.Name ASC,
         country.Code ASC,
         city.ID ASC;
```

The region value is supplied through a prepared statement rather than inserted directly into the SQL string.

## 4. Report Behaviour

- Retrieves cities belonging to the specified region.
- Orders cities by descending population, with deterministic ordering for ties.
- Formats population values with thousands separators.
- Displays `No cities found.` when no matching records exist.
- Rejects missing or blank region arguments.
- Returns a general error message for database failures without exposing connection details.
