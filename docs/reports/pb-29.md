# PB-29 — Selected Country Population

## Requirements

Report the population of a selected country.

Supported commands:

```text
PB-29 <country>
--population-country <country>
```

The query retrieves the population for the selected country from the country table using a parameterised country filter.

## Automated verification
The tests cover:

the selected country population;

unknown, missing, and blank country input;

both supported command forms;

readable output formatting; and

database errors without exposing connection details.

Run the suite with:


```bash
mvn clean verify
```

## Official World Database check
After starting the coursework database, compare the command output with this
direct equivalent query:

```sql
SELECT Name, Population
FROM country
WHERE Name = 'Slovakia';
```

Example application invocation:
```bash
java -jar target/population-reporting-system.jar PB-29 Slovakia
```

### Verified result:

Name | Population
Slovakia | 5,398,700
