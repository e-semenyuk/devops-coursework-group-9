# PB-01: Countries in the world by population

Issue: #8. [Use case](../USE_CASES/PB-01.md).

```bash
docker compose run --build --rm app PB-01
docker compose run --rm app --countries-world
```

Both command forms produce the same report. The report includes Code, Name,
Continent, Region, Population and Capital, ordered by population descending;
ties are ordered by country name and code. Countries are retained if their
capital is missing or its city record does not match the country. Missing
capitals display as `N/A`. Empty country data displays `No countries found.`
Invalid arguments exit 2, and database errors exit 1 without exposing connection
details.

The automated tests use an isolated H2 database in MySQL compatibility mode.
They cover all output columns, descending ordering and stable ties, matching and
invalid capital links, empty data, command aliases, invalid arguments, and safe
database errors. Run the focused tests with:

```bash
docker run --rm -u "$(id -u):$(id -g)" \
  -v "$PWD":/workspace -w /workspace \
  maven:3.9-eclipse-temurin-17 \
  mvn -Dtest=CountryReportTest test
```
