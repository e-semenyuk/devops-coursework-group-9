# PB-21: Top N capital cities in a continent

Issue: #28. Builds on the continent filter (PB-18) and Top N query (PB-20).

```bash
java -jar target/population-reporting-system.jar --top-capitals-continent "Europe" 5
docker compose run --build --rm app --top-capitals-continent "Europe" 5
```

Arguments are **continent, then N**. The continent must not be blank; quote names
containing spaces. N must be an integer from 1 to 2147483647. Both the continent
and limit are JDBC parameters. Filtering happens before ordering and limiting,
so a larger capital outside the selected continent cannot displace a match.
Fewer than N matches returns all matches; unknown continents produce a clear
empty-result message. Columns and exit statuses follow [PB-17](pb-17.md).

Tests cover filter-before-limit behaviour, excessive N, names containing spaces,
unknown/SQL-like filters, invalid N, blank continents and incorrect arguments.
Run `mvn clean verify`.
