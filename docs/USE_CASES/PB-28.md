## PB-28: Produce Selected Region Population

**Goal in Context:** As an Organisation User, I want to display the population of a specified region.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains valid region population data.  
**Success End Condition:** The population for the selected region is displayed.  
**Failed End Condition:** No population value is displayed when the region is invalid or the data is unavailable.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests the population of a region.

### Main Success Scenario
1. The Organisation User selects the region population option.
2. The system requests a region.
3. The Organisation User provides the region.
4. The system validates the region.
5. The system retrieves all country population values in the selected region.
6. The system sums the population values for the region.
7. The system displays the region population total.

### Extensions
- 4a. The region is not found: The system informs the user that no matching region exists.
- 5a. Required population data is unavailable: The system informs the user that the population cannot be displayed.
