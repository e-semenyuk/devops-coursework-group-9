## PB-27: Produce Selected Continent Population

**Goal in Context:** As an Organisation User, I want to display the population of a specified continent.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains valid continent population data.  
**Success End Condition:** The population for the selected continent is displayed.  
**Failed End Condition:** No population value is displayed when the continent is invalid or the data is unavailable.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests the population of a continent.

### Main Success Scenario
1. The Organisation User selects the continent population option.
2. The system requests a continent.
3. The Organisation User provides the continent.
4. The system validates the continent.
5. The system retrieves all country population values in the selected continent.
6. The system sums the population values for the continent.
7. The system displays the continent population total.

### Extensions
- 4a. The continent is not found: The system informs the user that no matching continent exists.
- 5a. Required population data is unavailable: The system informs the user that the population cannot be displayed.
