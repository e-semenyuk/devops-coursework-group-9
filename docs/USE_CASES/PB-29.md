## PB-29: Produce Selected Country Population

**Goal in Context:** As an Organisation User, I want to display the population of a specified country.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains valid country population data.  
**Success End Condition:** The population for the selected country is displayed.  
**Failed End Condition:** No population value is displayed when the country is invalid or the data is unavailable.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests the population of a country.

### Main Success Scenario
1. The Organisation User selects the country population option.
2. The system requests a country.
3. The Organisation User provides the country.
4. The system validates the country.
5. The system retrieves the population value for the selected country.
6. The system displays the country population total.

### Extensions
- 4a. The country is not found: The system informs the user that no matching country exists.
- 5a. Required population data is unavailable: The system informs the user that the population cannot be displayed.
