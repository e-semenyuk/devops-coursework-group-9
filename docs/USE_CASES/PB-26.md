## PB-26: Produce World Population Total

**Goal in Context:** As an Organisation User, I want to display the total population of the world.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains country population data.  
**Success End Condition:** The world population total is displayed.  
**Failed End Condition:** No total is displayed when population data is unavailable.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests the world population total.

### Main Success Scenario
1. The Organisation User selects the world population total.
2. The system retrieves all country population values.
3. The system sums the population values.
4. The system displays the total world population.

### Extensions
- 2a. Population data is unavailable: The system informs the user that the total cannot be calculated.
