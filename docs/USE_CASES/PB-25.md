## PB-25: Produce Population Distribution by Country Report

**Goal in Context:** As an Organisation User, I want to produce population distribution statistics for each country, including total population, population living in cities, population not living in cities, and the percentage for each category.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains the population data needed for the calculation.  
**Success End Condition:** A population-distribution report for each country is displayed with totals and percentages.  
**Failed End Condition:** The report is not displayed when the required data cannot be retrieved or calculated.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests population distribution by country.

### Main Success Scenario
1. The Organisation User selects the population-distribution-by-country report.
2. The system retrieves the required country and city population data grouped by country.
3. The system calculates total population for each country.
4. The system calculates population living in cities for each country.
5. The system calculates population not living in cities for each country.
6. The system calculates the corresponding percentages.
7. The system formats and displays the report for all countrys.

### Extensions
- 6a. Total population for a group is zero: The system reports the percentages for that group as N/A.
- 2a. Required population data is unavailable: The system informs the user that the report cannot be generated.
