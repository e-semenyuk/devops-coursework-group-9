## PB-17: Produce World Capital City Population Report

**Goal in Context:** As an Organisation User, I want to a report of all capital cities in the world.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains valid capital city population data.  
**Success End Condition:** A complete matching capital city report is displayed in descending population order.  
**Failed End Condition:** No report is displayed when the requested location is invalid or required data is unavailable.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests a report of all capital cities in the world.

### Main Success Scenario
1. The Organisation User selects the generate world capital city population report.
2. The system retrieves the required capital city data sorted by population in descending order.
3. The system formats the report with Name, Country, and Population.
4. The system displays the report.

### Extensions
- 5b. Required data is unavailable: The system informs the user that the report cannot be generated.
