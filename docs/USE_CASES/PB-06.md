## PB-06: Produce Top N Region Country Population Report

**Goal in Context:** As an Organisation User, I want to produce a report of the N most populated countries in a specified region.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains valid region and country population data.  
**Success End Condition:** A report containing up to N countries in the selected region is displayed in descending population order.  
**Failed End Condition:** No report is displayed for an invalid region, invalid N, or unavailable data.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests a Top N country report for a region.

### Main Success Scenario
1. The Organisation User selects the Top N countries-by-region report.
2. The system requests a region and N.
3. The Organisation User provides the region and N.
4. The system validates the region and N.
5. The system retrieves countries in the region ordered by population descending and limits the result to N.
6. The system formats and displays the report.

### Extensions
- 4a. The region does not exist: The system informs the user that no matching region was found.
- 4b. N is not a positive integer: The system asks for a valid positive integer.
- 5a. Fewer than N records are available: The system displays all available records.
