## PB-02: Produce Continent Country Population Report

**Goal in Context:** As an Organisation User, I want to produce a report of all countries in a specified continent ordered from largest to smallest population.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains valid continent and country population data.  
**Success End Condition:** A complete report for the selected continent is displayed in descending population order.  
**Failed End Condition:** No report is displayed for an invalid continent or unavailable data, and the user is informed of the problem.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests a country report for a continent.

### Main Success Scenario
1. The Organisation User selects the countries-by-continent report.
2. The system requests a continent.
3. The Organisation User provides the continent.
4. The system validates that the continent exists.
5. The system retrieves all countries in the continent.
6. The system sorts the countries by population in descending order.
7. The system formats and displays the report.

### Extensions
- 4a. The continent does not exist: The system informs the user that no matching continent was found.
- 5a. Country data is unavailable: The system informs the user that the report cannot be generated.
