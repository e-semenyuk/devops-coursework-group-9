## PB-18: Produce Continent Capital City Population Report

**Goal in Context:** As an Organisation User, I want to a capital-city report for a specified continent.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains valid capital city population data.  
**Success End Condition:** A complete matching capital city report is displayed in descending population order.  
**Failed End Condition:** No report is displayed when the requested location is invalid or required data is unavailable.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests a capital-city report for a specified continent.

### Main Success Scenario
1. The Organisation User selects the generate continent capital city population report.
2. The system requests continent.
3. The Organisation User provides continent.
4. The system validates continent.
5. The system retrieves the required capital city data sorted by population in descending order.
6. The system formats the report with Name, Country, and Population.
7. The system displays the report.

### Extensions
- 4a. Continent is invalid or not found: The system informs the user and does not generate the report.
- 5b. Required data is unavailable: The system informs the user that the report cannot be generated.
