## PB-16: Produce Top N District City Population Report

**Goal in Context:** As an Organisation User, I want to a Top N city report for a specified district.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains valid city population data.  
**Success End Condition:** A report containing up to N matching city records is displayed in descending population order.  
**Failed End Condition:** No report is displayed when N or the requested location is invalid, or required data is unavailable.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests a Top N city report for a specified district.

### Main Success Scenario
1. The Organisation User selects the generate top n district city population report.
2. The system requests district and N.
3. The Organisation User provides district and N.
4. The system validates district and that N is a positive integer.
5. The system retrieves the required city data sorted by population in descending order and limits the result to N records.
6. The system formats the report with Name, Country, District, and Population.
7. The system displays the report.

### Extensions
- 4a. District is invalid or not found: The system informs the user and does not generate the report.
- 4b. N is not a positive integer: The system asks the user to enter a valid positive integer.
- 5a. Fewer than N matching records are available: The system displays all available matching records.
- 5b. Required data is unavailable: The system informs the user that the report cannot be generated.
