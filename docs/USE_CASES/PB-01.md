## PB-01: Produce World Country Population Report

**Goal in Context:** As an Organisation User, I want to produce a report of all countries in the world ordered from largest to smallest population.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains valid country population data.  
**Success End Condition:** A complete country report is displayed, ordered by population descending, with Code, Name, Continent, Region, Population, and Capital.  
**Failed End Condition:** No report is displayed and the user is informed that the report could not be generated.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests the world country population report.

### Main Success Scenario
1. The Organisation User selects the world country population report.
2. The system retrieves all country records.
3. The system sorts the records by population in descending order.
4. The system formats the records using Code, Name, Continent, Region, Population, and Capital.
5. The system displays the report.

### Extensions
- 2a. Country data is unavailable: The system informs the user that the report cannot be generated.
