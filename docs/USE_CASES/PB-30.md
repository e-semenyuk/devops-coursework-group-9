## PB-30: Produce Selected District Population

**Goal in Context:** As an Organisation User, I want to display the population of a specified district.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains valid district population data.  
**Success End Condition:** The population for the selected district is displayed.  
**Failed End Condition:** No population value is displayed when the district is invalid or the data is unavailable.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests the population of a district.

### Main Success Scenario
1. The Organisation User selects the district population option.
2. The system requests a district.
3. The Organisation User provides the district.
4. The system validates the district.
5. The system retrieves all city population values in the selected district.
6. The system sums the city population values for the district.
7. The system displays the district population total.

### Extensions
- 4a. The district is not found: The system informs the user that no matching district exists.
- 5a. Required population data is unavailable: The system informs the user that the population cannot be displayed.
