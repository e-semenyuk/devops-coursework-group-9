## PB-03: Produce Region Country Population Report

**Goal in Context:** As an Organisation User, I want to produce a report of all countries in a specified region ordered from largest to smallest population.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains region and country population data.  
**Success End Condition:** A complete report for the selected region is displayed in descending population order.  
**Failed End Condition:** No report is displayed for an invalid region or unavailable data, and the user is informed of the problem.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests a country report for a region.

### Main Success Scenario
1. The Organisation User selects the countries-by-region report.
2. The system requests a region.
3. The Organisation User provides the region.
4. The system validates that the region exists.
5. The system retrieves all countries in the region.
6. The system sorts the countries by population in descending order.
7. The system formats and displays the report.

### Extensions
- 4a. The region does not exist: The system informs the user that no matching region was found.
- 5a. Country data is unavailable: The system informs the user that the report cannot be generated.
