## PB-31: Produce Selected City Population

**Goal in Context:** As an Organisation User, I want to display the population of a specified city.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains valid city population data.  
**Success End Condition:** The population for the selected city is displayed.  
**Failed End Condition:** No population value is displayed when the city is invalid or the data is unavailable.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests the population of a city.

### Main Success Scenario
1. The Organisation User selects the city population option.
2. The system requests a city.
3. The Organisation User provides the city.
4. The system validates the city.
5. The system retrieves the population value for the selected city.
6. The system displays the city population.

### Extensions
- 4a. The city is not found: The system informs the user that no matching city exists.
- 5a. Required population data is unavailable: The system informs the user that the population cannot be displayed.
