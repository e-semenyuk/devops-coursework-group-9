## PB-11: Produce District City Population Report

**Goal in Context:** As an Organisation User, I want to a city report for a specified district.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains valid city population data.  
**Success End Condition:** A complete matching city report is displayed in descending population order.  
**Failed End Condition:** No report is displayed when the requested location is invalid or required data is unavailable.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests a city report for a specified district.

### Main Success Scenario
1. The Organisation User selects the generate district city population report.
2. The system requests district.
3. The Organisation User provides district.
4. The system validates district.
5. The system retrieves the required city data sorted by population in descending order.
6. The system formats the report with Name, Country, District, and Population.
7. The system displays the report.

### Extensions
- 4a. District is invalid or not found: The system informs the user and does not generate the report.
- 5b. Required data is unavailable: The system informs the user that the report cannot be generated.
