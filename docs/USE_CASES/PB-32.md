## PB-32: Produce Major Language Population Report

**Goal in Context:** As an Organisation User, I want to produce a global report showing the number and percentage of people who speak Chinese, English, Hindi, Spanish, and Arabic, ordered from greatest to smallest number of speakers.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains country population and language-percentage data.  
**Success End Condition:** A report is displayed for Chinese, English, Hindi, Spanish, and Arabic showing estimated speaker totals and percentages of world population in descending order.  
**Failed End Condition:** The report is not displayed when the required population or language data cannot be retrieved or calculated.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests the major-language population report.

### Main Success Scenario
1. The Organisation User selects the major-language population report.
2. The system calculates the total world population.
3. The system retrieves language data for Chinese, English, Hindi, Spanish, and Arabic.
4. For each target language, the system calculates the estimated number of speakers.
5. The system calculates each language's percentage of the world population.
6. The system sorts the five languages by estimated speaker count in descending order.
7. The system formats and displays the report.

### Extensions
- 2a. World population data is unavailable: The system informs the user that the report cannot be generated.
- 3a. Data for one or more target languages is missing: The system identifies the incomplete language data and does not present the report as complete.
- 4a. A required numeric value is invalid: The system reports that the calculation cannot be completed for the affected language.
