## PB-04: Produce Top N World Country Population Report

**Goal in Context:** As an Organisation User, I want to produce a report of the N most populated countries in the world.

**Scope:** Population Reporting System  
**Level:** Primary Task  
**Preconditions:** The database is available and contains country population data.  
**Success End Condition:** A report containing up to N countries is displayed in descending population order.  
**Failed End Condition:** No report is displayed for an invalid N or unavailable data, and the user is informed of the problem.  
**Primary Actor:** Organisation User  
**Trigger:** The Organisation User requests a Top N world country report.

### Main Success Scenario
1. The Organisation User selects the Top N world countries report.
2. The system requests N.
3. The Organisation User provides N.
4. The system validates that N is a positive integer.
5. The system retrieves countries ordered by population descending and limits the result to N records.
6. The system formats and displays the report.

### Extensions
- 4a. N is not a positive integer: The system asks the user to enter a valid positive integer.
- 5a. Fewer than N country records are available: The system displays all available records.
- 5b. Country data is unavailable: The system informs the user that the report cannot be generated.
